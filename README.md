# 集换社量化分析 Agent

本地运行的卡牌交易分析系统。只把 **PSA10 且非套出** 的成交计入价格、收益和预测，金额单位是人民币。

## 启动

```bash
cd quant-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.seed
uvicorn app.main:app --host 127.0.0.1 --port 8787
```

浏览器打开 http://127.0.0.1:8787 。

## 给别人看

同一 Wi-Fi 里的人可以看，改数据仍然只在这台电脑上：

```bash
QUANT_SHARE=1 uvicorn app.main:app --host 0.0.0.0 --port 8787
```

把终端里打印的局域网地址发给对方，例如 `http://192.168.1.20:8787` 。你自己仍用 http://127.0.0.1:8787 录入。电脑要开着，对方要连同一个网络。macOS 第一次被访问时，如果弹出防火墙提示，允许 Python 接受连接。

不在同一网络的人打不开这个地址。要放到公网，需要一台一直在线的服务器，或用 Cloudflare Tunnel 之类的穿透。数据是交易记录，公开前先想清楚谁能看。

第一次启动时，如果数据库是空的，并且上级目录有 `集换社交易汇总数据.xlsx`，会自动导入。`python -m app.seed` 会清空后按该文件重建。

可选环境变量 `QUANT_API_TOKEN`：设置后，`/api` 需要 `Authorization: Bearer <token>`。`QUANT_EXCEL` 可指定初始 Excel 路径。

## 页面

- 总览：最新价、7 日 / 30 日收益、量变、规则建议、告警和事件
- 卡牌：双击总览卡片进入。日中位价、成交量、价量、波动率、回撤、分布、竞价、异常点
- 对比：多卡收益柱和起始价归一化走势
- 报告：十个章节，可导出 Word、Excel，或用浏览器打印成 PDF
- 录入 / 导入：单笔表单，或按现有汇总表批量导入
- 告警：七条规则，条件消失后自动解除
- 卡牌库：人口、事件、竞价快照、操作日志

## 计算口径

- 7/30/90 日收益：最新 PSA10 日中位价，相对 N 个自然日前最近一个成交日的中位价。样本跨度不够时显示 N/A
- 波动率：相邻有效交易日中位价收益率的标准差
- 最大回撤：样本内从高点到其后低点的最大跌幅
- 异常：IQR（1.5 倍）之外，或当日偏离中位价超过 50%，或高于均值 3 倍标准差
- 主图价格去掉 IQR 异常点；原始最高价仍写在读数里
- 预测：14/21/28 个有效交易日的对数价格，向后推 7 个和 30 个自然日，只作区间，不是目标价
- 强卖出：30 日收益低于 -20%，且最大回撤达到 -40% 或更深。文档里的不等号按“回撤至少 40%”理解，否则浅回撤也会被标成强卖出
